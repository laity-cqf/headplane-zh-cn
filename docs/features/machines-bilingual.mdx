# Machines guide

This guide describes `laity-cqf/headplane-zh-cn` on `main`. The development branch does not publish Docker images; deploy a published stable community release. See [Language and maintenance](/features/language) for release status.

### Browse and filter

Select **English** in the header and open **Machines**. Search by name or IP,
or filter by user, tag, status and route type. Open a machine to inspect its
routes, owner, expiry and addresses. Click an address or node key to copy it.
With the Headplane agent enabled, reported OS, Tailscale version, connectivity
and available-update notices follow upstream behavior.

### Register and manage

Select **Add machine → Register machine key**. Run the displayed
`tailscale up --login-server=...` command on the device, paste its registration
URL or full `hskey-authreq-...` key, choose an owner and submit. The command
itself is not a registration key. **Create auth key** opens the translated [Settings module](/features/settings-bilingual).

Use the machine menu to rename, approve subnet/exit routes, assign ACL tags,
manage expiry, change owner where supported, expire or remove a machine.
Names retain the DNS label rules: 1–63 ASCII letters, numbers or hyphens,
starting and ending with a letter or number. Undeclared tags show a policy
warning. Disabling expiry needs Headscale 0.29 or newer; changing owner is
available only on Headscale versions that support it.

Language selection preserves permission checks, version gates and API behavior.
Switching language persists per browser and preserves the route and filters.
Headscale diagnostics, commands, identifiers and user-provided values keep their
original spelling. Chinese errors add an explanation and HTTP status alongside
the original diagnostic. Browser SSH and Settings also support both languages.
